# Keep — expressive logo exploration

Created with the built-in ImageGen tool after the user requested a different,
more ambitious approach than the first geometric SVG concepts.

`keep-new-directions.png` is the concept-selection board. The exact prompt is
stored in `generation-prompt.txt`.

- **01 Sentinel:** watchful bird with a protected negative space; archival,
  characterful identity in ink and parchment.
- **02 Clasp:** soft abstract bands around a private interior; approachable
  software identity in aubergine and lilac.
- **03 Keepsake:** bespoke editorial wordmark and double-e ligature; warm,
  expressive identity in burnt red and cream.
- **04 Cocoon:** folded organic envelope; high-contrast identity in acid green
  and near-black olive.

Recommendation: develop Sentinel for a characterful symbol-led identity, or
Keepsake for a typography-led identity. Clasp is approachable but needs stronger
distinction from link symbols; Cocoon needs care to avoid reading as an
environmental brand.

These are raster concept renders, not production vector assets. Generated
lettering, contours, and color need refinement after selection. No favicon,
pixel-size, reversal, or trademark-clearance claims are made for this round.
The selected direction should be redrawn in SVG, optically refined, tested at
16/24/32 px and in both themes, and then exported as the full identity kit.
